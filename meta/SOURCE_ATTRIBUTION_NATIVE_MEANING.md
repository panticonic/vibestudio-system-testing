# Source attribution: native grounding and requested meaning

Inventory: `validateEvidence` in `open-goal-source-attribution-managed.ts` was used both by goal verification and the private-note admission/replay path. It required the authored reference path set, exact trace count, reference intent strings and reference boundary traversal. `matchedSourceAttributionReport` required equality to a reference disposition and constructed claims. `verifiedOwnedSourceReceipt` required a private expected persistence status, including optional permitted notes. These are one mechanism in three consumers; all are corrected together. `reference`/`reportConclusion` remain deterministic reference generation only. Other native engines do not implement this Vibe fixture's verifier; Host export/review consumes the proof and now has a mandatory sourceAttribution field map. Base semantic root, native read/trace/retention ports and the workflow catalog are coordinated consumers.

Actual admission now validates the scoped current file/frame, selected fragment, exact trace file/state/ranges, root custody and actual claim references/boundary identity. It accepts additional actual traces and explicit truncated evidence; it does not call those complete answers. Independent native graph/root rereads, unchanged source bytes/main head, current authority, exact request replay, closed/stale refusal, protected neighboring state and note byte readback remain crisp. Meaning and requested coverage are independently reviewed against actual facts, not hidden reference paths, words, counts or status enums.

Every source-attribution goal requires bound semantic review. Its actual value is carried as actualResult. Observations are assignment/files/evidence/effects/native; artifacts are receipt and independently read retainedText. Only the original goal is expected. Requested note persistence, query explanation, copied-vs-local causality, stated-vs-mechanical intent and truthful limits remain real obligations in that review. An empty explanation is not accepted merely because current reads were authentic. Unknown or uninspected claim/root references are still rejected crisply.

Native note retention records the actual conclusion, including its uncertainty disposition, under current scope/authority. An accurate requested unresolved note need not invent a claim to pass a private nonempty-claims gate. Permission itself does not require a note. No original captured verdict, raw bytes, source IDs, goals or splits are rewritten.
