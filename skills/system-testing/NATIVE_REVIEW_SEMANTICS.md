# Native evidence semantics for goal review

Three actual wave0063 review-only failures exposed missing domain semantics in otherwise bound review input. Inventory: Chat's sole `bindObservedContentReview` consumer supplies index/frames/evidence/artifact; the Host's `observed-content-admission` independently reconstructs exactly those proof fields. OwnedTask supplies captured effect args/results, current task and exact original receipt; all inspections and send guards live in `open-goal-owned-task-managed.ts`. Both feed the shared Base `observed-content-review`, independent Host reviewer, archived proof and native IR readers. No actor service or engine protocol changes are needed. New facts stay inside the existing native evidence field, so every binder/reader sees the same exact values; all prior checks and review requirements remain.

`joinWorker` validates the original participant target; `retainedWorkerRelationship` tracks opened/revised/ended revisions; `workerState` independently inspects that participant. Native objectKey/participantId remain identical after a legitimate detach/rejoin. A new membership revision is not a new object. Facts now expose those equality relations without converting them into a desired verdict. Replacement handles and inactive originals remain distinct negatives.

A goal asking for a private diagnostic may be satisfied by a correctly retained hold, while a ready-only or actual repair request still requires the requested current state. Review guidance must not silently convert diagnosis into repair. The native fixture exposes only list/read/stage, so no authority to alter transcript/worker lifecycle is added.

OwnedTask receipt metadata locates the exact accepted artifact; it does not contain file bytes. Explicit-recipient inspection owner:null and maySend:false are native lookup/permission results, not an omitted membership check. A conditional send cannot require an unauthorized send. Returning explicitly requested numeric contents remains a separate real requirement and cannot be waived. Original review and packet bytes remain immutable; no success is inferred solely from this guidance change.
