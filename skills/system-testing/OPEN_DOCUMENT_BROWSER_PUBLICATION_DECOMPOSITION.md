# Document, browser, and publishing goal expansion

| Goal surface | Reused policy and exact readback |
| --- | --- |
| Live browser controls | The shared root and its browser chooser interpret the request. The original renderer supplies control identities and row states. The verifier independently checks the exact interaction order, each intermediate revision, selected rows, and all untouched rows. |
| Spectrolite working documents | The installed vault policy decides what to navigate, revise, or review. CDP observes links and previews on one renderer; semantic VCS protects committed and main state and preserves other files, draft edits, and exact source. |
| Website readiness | The installed publication policy selects a destination and whether to inspect packaging, a journal operation, or a retained review. Exact source and package identities, the original renderer, and local journal readbacks decide the proof. No provider is used. |
| PDF-backed working corrections | The installed PDF and Spectrolite subtrees form one goal. The handoff carries verified document bytes, page and quotation coordinates before releasing the vault services. Missing approved pages block writes. A real semantic update can intervene at the first write. |

Authored inputs live in separate source groups. Each surface has its own held
sources. Expected dispositions, routes and file contents remain in private
runner definitions.
